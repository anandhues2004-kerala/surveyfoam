
# 📋 Survey Form (HTML)

## 📖 Project Description

This project is a **simple Survey Form** created using **HTML only**.
It collects basic user information such as **name, email, age**, and feedback about a session.

This project is ideal for **HTML beginners** to understand form elements like:

* Input fields
* Radio buttons
* Checkboxes
* Dropdown menus
* Textarea
* Fieldsets

---

## 🛠️ Technologies Used

* **HTML5**

(No CSS or JavaScript used)

## 🧩 Form Sections Explained

### 1️⃣ Basic User Information

The form collects:

* **Name** (text input)
* **Email** (email input)
* **Age** (optional number input)

```html
<input type="text">
<input type="email">
<input type="number">
```

---

### 2️⃣ Current Role Selection

Users select their current role from a **dropdown menu**.

```html
<select>
  <option>role1</option>
  <option>role2</option>
</select>
```

---

### 3️⃣ Session Feedback (Radio Buttons)

Users answer whether the session was interactive using **radio buttons**:

* Yes
* No

```html
<input type="radio">
```

---

### 4️⃣ Improvement Suggestions (Checkboxes)

Users can select **multiple options** for improvements:

* More projects
* Student recap
* Live Q&A
* Less homework

```html
<input type="checkbox">
```

---

### 5️⃣ Additional Comments

Users can write their feedback in a **textarea**.

```html
<textarea rows="3" cols="30"></textarea>
```

---

### 6️⃣ Submit Button

Submits the survey form.

```html
<input type="submit">
```

1. Download or clone the project
